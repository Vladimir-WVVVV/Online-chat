# OnlineChat 系统测试报告

## 1. 测试环境

- 日期：2026-06-10
- 后端：Java 17、Spring Boot 3.3.5、Maven、H2（自动化测试）/ MySQL 8（部署）
- 前端：Vue 3、Vite 5、Node.js、Element Plus
- 实时通信：STOMP WebSocket、WebRTC
- 浏览器目标：Chrome、Edge、Firefox 当前稳定版
- AI 模型配置：`glm-4.5-flash`；未配置真实 Key 时使用 Mock Provider

## 2. 测试账号与安全说明

系统默认不创建演示账号。需要本地课程演示时，可设置 `DEMO_SEED_USERS=true` 创建
`alice`、`bob`、`carol`、`admin`，初始密码均为 `123456`。

这些账号仍严格经过数据库查询、BCrypt 密码校验和 JWT 签发，不是硬编码登录后门。正式环境必须保持
`DEMO_SEED_USERS=false`，并清理演示账号或修改密码。登录页不预填账号密码。

## 5. 响应式布局检查

| 视口 | 预期 |

| 小于等于 720px | 列表与聊天区单页切换；聊天页提供返回按钮；工具按钮换行；弹窗适配屏宽 |

重点检查消息气泡、图片消息、AI 卡片、底部输入框、添加好友、好友申请、创建群聊和语音来电弹窗均不横向溢出。

## 6. AI 与语音结论

三类 AI 回复统一由后端生成，写入 `message` 表，并通过正常 WebSocket 会话推送。私聊 AI 消息使用
`receiver_id` 和 `group_id` 记录会话双方 userId，双方历史查询均可加载；群聊按 groupId 广播。

浏览器麦克风采集要求安全上下文。`localhost` 可使用 HTTP，公网或局域网 IP 演示必须配置 HTTPS；
跨 NAT 通话还可能需要 TURN 服务。系统不会在不支持环境中伪装通话成功，而会禁用按钮并显示明确原因。

## 7. 测试结论

核心认证、资料、好友、私聊/群聊、AI 正式消息流和基础语音信令均已覆盖。课程验收前应在实际 HTTPS
部署地址使用 Chrome、Edge、Firefox 各执行一次第 1-14 项，并记录浏览器版本与截图。
